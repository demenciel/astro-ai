# Getting the keys (tell the user exactly this)

Ask the user to paste values into `.env.setup` themselves (copy from `.env.setup.example`),
not into the chat. Then run `npm run status` to see which are set. Only Cloudflare is required.

| Key                                           | Required     | Where                                                                                                                                                                          | Notes                                                                                                                                                                                                                                  |
| --------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CLOUDFLARE_API_TOKEN`                        | yes (deploy) | https://dash.cloudflare.com/profile/api-tokens → Create Token → template **Edit Cloudflare Workers** → add permissions **Account · D1 · Edit** and **Account · Queues · Edit** | Account id is auto-detected. Free plan is enough. If the account never opened Workers, ask the user to open _Workers & Pages_ once so a `workers.dev` subdomain exists.                                                                |
| `GITHUB_TOKEN`                                | no           | https://github.com/settings/personal-access-tokens/new → only this repo → Repository permissions **Secrets: Read and write**                                                   | Skippable if `gh auth login` is done. Enables deploy-on-push.                                                                                                                                                                          |
| `STRIPE_SECRET_KEY`, `STRIPE_PUBLISHABLE_KEY` | no           | https://dashboard.stripe.com/test/apikeys                                                                                                                                      | Start with **test** keys (`sk_test_`). Setup creates products/prices from `src/data/plans.json` and the webhook (`STRIPE_WEBHOOK_SECRET`) automatically. Switch to live keys later and re-run `npm run setup -- --only=stripe,deploy`. |
| `OPENAI_API_KEY`                              | no           | https://platform.openai.com/api-keys                                                                                                                                           |                                                                                                                                                                                                                                        |
| `ANTHROPIC_API_KEY`                           | no           | https://console.anthropic.com/settings/keys                                                                                                                                    |                                                                                                                                                                                                                                        |
| `GEMINI_API_KEY`                              | no           | https://aistudio.google.com/apikey                                                                                                                                             | Has a free tier.                                                                                                                                                                                                                       |
| `XAI_API_KEY`                                 | no           | https://console.x.ai                                                                                                                                                           | Grok.                                                                                                                                                                                                                                  |
| `DEEPSEEK_API_KEY`                            | no           | https://platform.deepseek.com/api_keys                                                                                                                                         |                                                                                                                                                                                                                                        |
| `ADMIN_PASSWORD`, `SESSION_SECRET`            | auto         | generated by `npm run setup`                                                                                                                                                   | Tell the user the admin password lives in `.env.setup`.                                                                                                                                                                                |

Missing optional keys never break anything: features check for their key and hide/disable themselves.
